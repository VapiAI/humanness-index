# The Humanness Index

An open, blind-vote benchmark for how human text-to-speech models sound.
Listeners hear two models read the same prompt with the same cloned source
voice and pick whichever sounds more human; every score derives purely from
those votes.

Currently live at [vapi.ai/humanness-index](https://vapi.ai/humanness-index)
while the standalone extraction happens here. See [SPEC.md](./SPEC.md) for
the extraction, hosting, and open-sourcing plan.

Built and operated by [Vapi](https://vapi.ai).
